# BAS World

The handbook's case company (see `context.md` §2). It shows what stays hard once budget and IT are no longer the limit; it does not describe the sector average, so its claims are always labelled `case`.

## What the library says

- Its AI agents run on a modular, vendor-agnostic foundation hosted on AWS [W2-021].
- Models are swappable: ChatGPT, Gemini and Claude are plug-and-play [W2-022].
- The agents run on its implementation partner's building block, designed so BAS World can carry on without that partner [W2-023].

All three come from the implementation partner's case study: company-reported, not independently checked.
