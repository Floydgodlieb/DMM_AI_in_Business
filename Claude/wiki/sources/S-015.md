# S-015 · "Data, Privacy, and Security for Microsoft Copilot"

## What it says

- Copilot's model calls normally go to the nearest regional data centre, but can go to other regions when capacity runs out [W2-028].
- EU traffic is kept inside the EU Data Boundary with extra safeguards [W2-029].
- Models supplied by Anthropic as a subprocessor are currently excluded from that boundary [W2-030].
